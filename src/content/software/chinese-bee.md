Two Sticks is a Telegram prototype for learning Chinese characters. I designed the product and built the bot, the API, and the handwriting web app. The original bot and repository names used Chinese Bee. The prototype is no longer hosted because keeping its backend online has an ongoing cost.

The working loop is one saved set. Look up a word, keep it, parse it on a notebook sheet, recall it with flashcards, then write it on a canvas that returns a score. Teacher live-marking and an HSK dashboard were in the brief and did not ship.
