# chinese bot case study ground

Two Sticks / Две палочки is a Telegram prototype for learning Chinese characters. The implementation and repositories used the name Chinese Bee.

Igor designed the product and built it: `chinesebee_bot`, `chinesebee_api`, `chinese-bee-dictation`.

The pedagogical research is a 2024 MPGU diploma by Смакова, Шаталова, Шинкарева: copybook pains, competitive frame (Skritter, Duolingo, HelloChinese, Telegram bots), memorisation methods, open-day masterclass (15 of 20 interested).

Shipped: search, details, saved set, five-word flashcard gate, notebook sheets in chat, Vue Web App dictation with OCR score, character primer, facts.

Did not ship: live teacher board, HSK statistics dashboard, the planned growth engine.

The Russian bot is no longer hosted because its backend has an ongoing infrastructure cost. The source repositories and surviving interface captures remain available as evidence.
